# Персональный веб-ресурс портфолио на базе Flask

Данный репозиторий содержит обновленную версию адаптивного веб-приложения, разработанного на базе микрофреймворка Flask. Ресурс функционирует как структурированный отчет и персональный трекер, отражающий процесс освоения технологий серверной и клиентской веб-разработки.

Текущая итерация проекта сфокусирована на внедрении динамических шаблонов, наследовании структуры и реализации механизмов сбора и обработки пользовательских данных.


## Новая функциональность и архитектурные изменения

1. **Наследование шаблонов (Jinja2):** Создан базовый каркас `index.html` с единой навигационной панелью. Страница хроники наследует общую структуру, исключая дублирование HTML-кода.
2. **Интерактивный «Дневник программиста»:** Реализован новый изолированный маршрут `/notes`. Добавлена POST-форма для отправки заголовков и текста выполненных работ.
3. **Динамическое хранение данных:** Организован прием данных из веб-формы и их последующая запись во временное хранилище (словарь Python) с выводом на страницу в виде информационных карточек.
4. **Оптимизация мониторинга успеваемости:** Архитектура таблицы на главной странице переведена на динамический цикл. Для предотвращения деформации интерфейса внедрена фиксированная ширина ячеек и принудительный перенос строк заголовков через фильтр `| safe`.


## Структура проекта

```text
flask_app/
├── static/
│   ├── css/
│   │   └── style.css      # Стили фиксированной таблицы, форм и карточек
│   └── images/
│       └── logo.png       # Графический элемент профиля разработчика
├── templates/
│   ├── index.html         # Базовый каркас приложения и главная страница
│   └── notes.html         # Наследуемый шаблон страницы дневника с формой
├── app_2.py               # Серверный скрипт (маршрутизация, обработка POST)
└── README.md              # Документация текущей ветки
```

## Инструкция по запуску

### 1. Подготовка окружения
Рекомендуется использовать виртуальное окружение. Создайте и активируйте его:

**Для Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**Для macOS / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 2. Установка зависимостей
Установите фреймворк Flask с помощью пакетного менеджера `pip`:
```bash
pip install flask
```

### 3. Добавление ресурсов
Убедитесь, что в папку `static/` добавлено изображение с именем `logo.png`. Если изображение имеет другое расширение (например, `.jpg`), обновите строку подключения в файле `templates/index.html`.

### 4. Запуск сервера
Запустите главный файл приложения:
```bash
python app_2.py.py
```

После запуска в консоли появится техническое предупреждение `WARNING: This is a development server...`. Это нормальное поведение для встроенного сервера разработки.

### 5. Просмотр сайта
Откройте любой веб-браузер и перейдите по адресу:
```text
http://127.0.0.1:5000/
```
