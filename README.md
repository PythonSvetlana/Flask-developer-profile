# Персональный веб-ресурс портфолио на базе Flask

Данный проект представляет собой адаптивное веб-приложение, разработанное на базе микрофреймворка Flask. Ресурс функционирует как структурированный отчет и персональный трекер, отражающий процесс освоения технологий серверной и клиентской веб-разработки, а также текущий академический прогресс по ключевым дисциплинам.


## Структура проекта

```text
flask_app/
├── static/
│   ├── css/
│   │   └── style.css      # Файл со стилями элементов (CSS)
│   └── images/
│       └── logo.png       # Графический элемент профиля разработчика
├── templates/
│   └── index.html         # HTML-шаблон главной страницы сайта
├── app_2.py               # Главный скрипт инициализации и запуска Flask
└── README.md              # Документация проекта
```


## Инструкция по запуску

### 1. Подготовка окружения
Рекомендуется использовать виртуальное окружение. Создайте и активируйте его:

**Для Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**Для macOS / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 2. Установка зависимостей
Установите фреймворк Flask с помощью пакетного менеджера `pip`:
```bash
pip install flask
```

### 3. Добавление ресурсов
Убедитесь, что в папку `static/` добавлено изображение с именем `logo.png`. Если изображение имеет другое расширение (например, `.jpg`), обновите строку подключения в файле `templates/index.html`.

### 4. Запуск сервера
Запустите главный файл приложения:
```bash
python app_2.py.py
```

После запуска в консоли появится техническое предупреждение `WARNING: This is a development server...`. Это нормальное поведение для встроенного сервера разработки.

### 5. Просмотр сайта
Откройте любой веб-браузер и перейдите по адресу:
```text
http://127.0.0.1:5000/
```
