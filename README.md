# Персональный веб-ресурс портфолио на базе Flask (Версия — Auth)

Ресурс функционирует как структурированный отчет и персональный трекер, отражающий процесс освоения технологий серверной и клиентской веб-разработки.

Текущий этап разработки сфокусирован на интегрировании полноценной подсистемы аутентификации пользователей и динамического контроля сессий. 


## Новая функциональность и архитектурные изменения

* **Аутентификация на базе Flask-Login:** Реализовано разграничение доступа. Доступ к личному кабинету (`/`) и «Дневнику программиста» (`/notes`) открывается только после прохождения авторизации.
* **Безопасное хранение данных (СУБД SQLite):** Пароли пользователей не хранятся в открытом виде. Использовано криптографическое одностороннее хеширование с солью по алгоритму `PBKDF2:SHA256` средствами библиотеки `Werkzeug`.
* **Динамические токены доступа:** При регистрации и каждом последующем входе в систему для пользователя генерируется уникальный системный токен в формате `UUID4`, который отображается в его профиле.
* **Монолитная архитектура шаблонов:** Оптимизирована верстка интерфейсов.

## Инструкция по запуску

### 1. Подготовка окружения
Рекомендуется использовать виртуальное окружение. Создайте и активируйте его:

**Для Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**Для macOS / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 2. Установка зависимостей
Установите фреймворк Flask с помощью пакетного менеджера `pip`:
```bash
pip install flask
```

### 3. Добавление ресурсов
Убедитесь, что в папку `static/` добавлено изображение с именем `logo.png`. Если изображение имеет другое расширение (например, `.jpg`), обновите строку подключения в файле `templates/index.html`.

### 4. Запуск сервера
Запустите главный файл приложения:
```bash
python app_2.py.py
```

После запуска в консоли появится техническое предупреждение `WARNING: This is a development server...`. Это нормальное поведение для встроенного сервера разработки.

### 5. Просмотр сайта
Откройте любой веб-браузер и перейдите по адресу:
```text
http://127.0.0.1:5000/
```
