# Персональный веб-ресурс портфолио на базе Flask (Версия — СУБД)

Ресурс функционирует как структурированный отчет и персональный трекер, отражающий процесс освоения технологий серверной и клиентской веб-разработки.

Текущий этап разработки сфокусирован на интеграции полноценного слоя хранения данных с использованием ORM-архитектуры и внедрении инструментов контроля версий базы данных.


## Новая функциональность и архитектурные изменения

1. **Реляционная архитектура хранения:** Реализована ORM-модель `Notes` для персистентного хранения информации. Структура БД расширена путем добавления сущностей:
   * `id` (Первичный ключ, Integer)
   * `title` (Заголовок записи, String)
   * `subtitle` (Подзаголовок/Привязка к теме, String)
   * `text` (Содержательная часть записи, Text)
2. **Интерактивный контроллер обработки данных:** Маршрут `/notes` модернизирован для работы со слоем данных. Реализован безопасный прием POST-запросов из веб-формы интерфейса с последующей фиксацией объектов в СУБД (`db.session.commit()`) и выгрузкой полной хроники в обратном хронологическом порядке.
3. **Контроль версий базы данных:** Инициализирована система миграций, позволившая безопасно модифицировать структуру таблиц без потери накопленных данных.


## Структура проекта

```text
flask_app/
├── migrations/            # Служебные скрипты и история версий структуры БД
├── static/
│   ├── css/

```

## Инструкция по запуску

### 1. Подготовка окружения
Рекомендуется использовать виртуальное окружение. Создайте и активируйте его:

**Для Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**Для macOS / Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 2. Установка зависимостей
Установите фреймворк Flask с помощью пакетного менеджера `pip`:
```bash
pip install flask
```

### 3. Добавление ресурсов
Убедитесь, что в папку `static/` добавлено изображение с именем `logo.png`. Если изображение имеет другое расширение (например, `.jpg`), обновите строку подключения в файле `templates/index.html`.

### 4. Запуск сервера
Запустите главный файл приложения:
```bash
python app_2.py.py
```

После запуска в консоли появится техническое предупреждение `WARNING: This is a development server...`. Это нормальное поведение для встроенного сервера разработки.

### 5. Просмотр сайта
Откройте любой веб-браузер и перейдите по адресу:
```text
http://127.0.0.1:5000/
```
